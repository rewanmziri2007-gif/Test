# Major

Website for the Major chess variant (game, Bot, accounts, Shorts, Chat, Photo App, League, Clan).

## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension.
3. Right-click `index.html` > "Open with Live Server".

You can also just double-click `index.html`.

## Files
- `index.html` page structure
- `style.css` styling
- `app.js` game engine and all app features

## Notes
All data is saved in the browser (localStorage), so accounts, Shorts, Chat, and Clans only work on one device.
Google sign-up, real-player matching, and voice calls are simulated and need a backend server to be real.
